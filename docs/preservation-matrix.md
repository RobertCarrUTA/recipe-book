# Feature preservation and regression matrix

This matrix maps maintained application capabilities to their protecting tests. The redesign preserved behavior from baseline `3117d47b9cdd3a844d063fbde2ca6cd5ff3a83d2` and merged in [PR #180](https://github.com/RobertCarrUTA/recipe-book/pull/180). Recipe source content remains the authoring boundary; shopping multipliers do not rewrite authored recipes.

See [archived release evidence](redesign-history.md), [performance budgets](performance-budgets.md), and the [data migration/recovery contract](data-recovery.md). A listed test is a coverage reference, not a claim that an untested future revision passes it.

Test abbreviations: [RC](../frontend/features/recipes.test.tsx) = recipe components; [KC](../frontend/features/kitchen.test.tsx) = kitchen components; [KW](../tests/e2e/kitchen-workflows.spec.ts) = browser kitchen workflows; [DR](../tests/e2e/data-recovery.spec.ts) = browser data recovery; [RB](../tests/e2e/robustness.spec.ts) = browser failure/hostile-content cases; [DS](../tests/e2e/design-system.spec.ts) = themes, viewports, axe and keyboard. Named Node suites below remain in `tests/` and protect the shared `js/` domain modules.

## Deliberate changes from the original app

- Browse uses batches of 24 at all widths rather than the old 24 desktop/16 compact split. Grocery options default collapsed for new state; explicit saved expanded/collapsed choices are retained. Search state updates immediately, with deferred rendering instead of the old 150 ms input debounce.
- The new UI adds Light/Dark/System and a print stylesheet. The old app had one dark palette and no print control. Both versions have one grocery list, a weekly template rather than dated meal slots, no recipe editing or interactive user ratings, no cooking timers, and no persisted cooking progress.
- #172/#141 resolved the reproduced legacy multiplier loss, malformed-backup reset and partial multi-key writes. Atomic v7 snapshots and a version fence preserve complete state; [compatible recovery and rollback limits](data-recovery.md) remain part of the contract.
- The cutover removes 25 unused DOM/controller modules, the old stylesheet, 18 tests tied to those implementations, and three old smoke/static-inventory scripts. Twenty-one shared domain modules and their tests remain. The mixed browser helper suite retains its three clipboard cases. Unique lifecycle, collection, download, routing and wake-lock contracts were ported to tests of the actual replacement before removal. Historical worker and v6 storage fixtures remain.
- Version 10 fixed the reproduced initial offline-error/loading shift; startup/large-list and supplemental journey measurements passed all 46 budgets at release. The [completed release record](redesign-history.md) links exact provenance and retained failures. Repeat the relevant checks for subsequent changes.
